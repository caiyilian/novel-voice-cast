# Novel Voice Cast — 插图生成环境配置

---

## 背景

现有一个小说转有声书项目（Novel Voice Cast），已完成文本解析→角色识别→情感标注→TTS→BGM→人声提取全流程。

下一步：**为小说关键场景生成配图**。要求：
- 用户提供角色参考图 → 生成插图时角色长相保持一致（类似音色克隆的理念）
- 用户不提供参考图 → 纯文本 prompt 生成默认效果
- 动漫/插画风格
- **不训练模型，只用社区现成的预训练权重**
- **零样本（zero-shot）推理，不微调、不训练 LoRA**
- **在 24GB 显存的 GPU（RTX 4090）上运行**

## 技术方案

使用 **SDXL + PuLID v1.1**：

| 组件 | 作用 | 显存 | 链接 |
|------|------|------|------|
| SDXL base 1.0 | 基座画图模型（2.6B 参数） | ~6GB | https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0 |
| PuLID v1.1 | 身份保持插件，让角色长得像参考图 | ~2GB | https://github.com/ToTheBeginning/PuLID |
| InsightFace (antelopev2) | 人脸检测，提取面部嵌入 | — | — |
| 动漫微调模型（可选） | 替换 SDXL 基座，提升动漫风格 | ~6GB | Illustrious / RouWei-0.6 / Anima 等 |

PuLID 的 `app_v1_1.py` 原生支持 SDXL，无需改代码。

## 硬件

- GPU：NVIDIA，**24GB 显存**（RTX 4090 测试通过）
- 系统：Linux
- 存储：至少 30GB

## 环境要求

1. **在项目目录下创建 uv 虚拟环境**，Python 3.10，生成 `.venv/` 文件夹
2. **PyTorch 用 whl 文件离线安装**，不要自动下载。版本要求：
   - Python 3.10 / CUDA 12.4 / torch 2.6.0
   - 需要 torch + torchvision + torchaudio 三个 whl
3. **其余依赖**：diffusers + transformers + accelerate + safetensors + opencv-python + insightface + onnxruntime-gpu + gradio
4. **代理**：服务器无代理软件，但同局域网有台机器开了 7890 端口。如需要联网：
   ```
   unset all_proxy && unset ALL_PROXY && unset http_proxy && unset https_proxy
   unset HTTP_PROXY && unset HTTPS_PROXY
   export http_proxy=http://<本地机器局域网IP>:7890
   export https_proxy=http://<本地机器局域网IP>:7890
   ```
   把 `<本地机器局域网IP>` 替换为实际 IP。

## 模型权重

**不要自动下载。** 需要用户手动下载：

| 权重 | 下载源 | 存放位置 |
|------|--------|---------|
| PuLID v1.1 | HuggingFace `guozinan/PuLID` → `pulid_v1.1.safetensors` | `models/pulid/` |
| InsightFace antelopev2 | ModelScope 搜索 `facefusion/insightface-models` | `~/.insightface/models/antelopev2/` |

SDXL 基座模型不需要手动下载，首次运行 `from_pretrained` 时会自动缓存。如果也要离线，从 ModelScope 下载 `stabilityai/stable-diffusion-xl-base-1.0` 全套。

## 功能要求

参考 PuLID 项目中的 `app_v1_1.py` 实现（不需要从零写，直接基于它改）：

### 有参考图模式（主模式）

- **输入**：角色参考图（一张人脸清晰的图片）+ 文本 prompt（场景描述）
- **输出**：保持角色长相的插图

### 无参考图模式（回退）

- **输入**：文本 prompt
- **处理**：直接用 SDXL 文生图，不需要加载 PuLID 和 InsightFace
- **输出**：普通插图

### 验证

- 有参考图时角色长相与参考图一致
- 两张不同 prompt 用同一张参考图 → 角色长相一致
- 如果替换为动漫微调基座（如 Illustrious）→ 效果更好且不改逻辑

## 约束

- ❌ 不训练任何模型
- ❌ 不自动下载 torch 和模型权重
- ❌ 不修改 PuLID 源码去适配其他基座（`app_v1_1.py` 已经支持 SDXL）
