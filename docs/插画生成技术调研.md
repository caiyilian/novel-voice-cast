# 插画生成技术调研

> 调研日期：2026-06-30
> 目标：为小说自动生成角色一致性插画，支持参考图驱动（类似音色克隆）
>
> ⚠️ **核心约束：不训练模型，只使用社区现成的预训练权重。**

---

| 资源 | 配置 | 可用显存 | 用途 |

## 一、需求明确

插画生成的核心需求不是"纯文生图"，而是：

1. **给角色参考图 → 保持长相一致生成新场景**（跟音色克隆一模一样）
2. 用户不提供参考图 → 纯文本 prompt 生成默认效果
3. 动漫/插画风格
4. 能复用现有场景分割 + 情感标注数据

## 二、身份保持（Identity Preservation）方案

### 2.1 PuLID — 纯 Lightning ID 定制 ⭐ 首推

> GitHub: https://github.com/ToTheBeginning/PuLID  
> 论文: NeurIPS 2024  
> 最新: PuLID-v1.1 (SDXL), PuLID-FLUX-v0.9.1 (FLUX)

**核心能力**：零样本（无需训练），给一张参考人脸 → 生成保持身份的新图。同时保持背景、光照、构图、风格不变。

**关键特性**：
- **PuLID-SDXL**：12GB 显存可用 ✅ 本地 RTX 3060 可跑
- **PuLID-FLUX**：16GB 显存可用，4090 上流畅
- 对比对齐损失（contrastive alignment loss）+ 精确 ID 损失
- 身份保真度 + 可编辑性的平衡最好

**显存需求**：

| 版本 | 基座模型 | 最低显存 | 推荐显存 | 适用硬件 |
|------|---------|---------|---------|---------|
| PuLID v1.1 | SDXL | **12GB** ✅ | 16GB | RTX 3060 / 4090 |
| PuLID-FLUX v0.9.1 | FLUX.1 | **16GB** | 24GB | 4090 / A100 |

**与现有项目的结合**：
- 用户提供角色参考图 → PuLID 提取面部嵌入 → 生成新场景插图时保持长相一致
- 不提供参考图 → 退化为纯文生图（SDXL/FLUX 原生能力）

---

### 2.2 InstantCharacter（腾讯）— FLUX 角色保持

> GitHub: https://github.com/Tencent/InstantCharacter  
> 更新: 2025-05

**核心能力**：单张参考图 → 保持角色身份生成任意场景，基于 FLUX.1-dev。

**关键特性**：
- 零样本，无需训练
- 使用 SigLIP + DINOv2 双图像编码器提取角色特征
- 1024 个 ID token 注入
- 支持风格 LoRA 叠加（如吉卜力风格）
- 已支持 offload 模式，**22GB 显存可跑**

**显存需求**：

| 模式 | 显存 | 适用硬件 |
|------|------|---------|
| 正常推理 | ~30GB | 4090 / A100 |
| Offload 模式 | **~22GB** | 4090 ✅ |
| ComfyUI 版 | 待测试 | — |

**注意**：目前动物角色不太稳定。

---

### 2.3 InstantID — 零样本身份保持

> GitHub: https://github.com/instantX-research/InstantID  
> 论文: 2024

**核心能力**：单张参考图 → 零样本身份保持生成，基于 SDXL。

**关键特性**：
- 最早的身份保持方法之一，生态成熟
- InsightFace 面部编码 + ControlNet 结构引导
- 可调节 ip_adapter_scale 控制身份强度 vs 风格自由度
- **16GB+ 显存**

**显存需求**：SDXL 版约 16GB，4090 流畅，3060 12GB 可能不够。

---

### 2.4 FLUX.2 [klein] — 原生多参考支持

> 发布: 2026  
> 模型: 4B 参数（轻量）

**核心能力**：Black Forest Labs 最新，原生支持最多 10 张参考图，**精确品牌色控制**、多参考编辑。

**关键特性**：
- **~13GB VRAM** ✅ 本地 3060 勉强可跑
- 官方 API 和 playgroud 支持多参考
- 开源权重 Apache 2.0（schnell 版）
- 结构提示（structured prompting）

**显存需求**：klein 4B 约 13GB，3060 12GB 可能略超，但 GGUF 量化可降至 10GB。

---

### 2.5 IP-Adapter-FaceID

> Hugging Face: h94/IP-Adapter-FaceID

**核心能力**：Face embedding 条件注入，SDXL/FLUX 都可用。

**关键特性**：
- 轻量，SDXL 上约 10GB 可跑
- FaceID v2 使用 insightface 面部嵌入
- 适合作为辅助方案

## 三、基础模型选型

### 3.1 SDXL 生态（推荐起步）

| 指标 | 数值 |
|------|------|
| 显存 | **8GB**（原生） |
| 速度 | RTX 4090 上 ~6s/张 |
| 动漫生态 | 最丰富：5000+ LoRA、大量动漫模型（Illustrious、Pony、Anime） |
| ControlNet | 5+ 种 |
| 授权 | OpenRAIL++ |

**适合 3060 12GB 的动漫模型**：
- **Illustrious-xl** — 动漫特化，SDXL 微调
- **RouWei-0.6** — 基于 Illustrious，22000+ 画师风格，中文友好
- **Pony** — 动漫质量高，标签系统成熟
- **Anima** — 专为二次元设计的模型，ComfyUI 生态

### 3.2 FLUX 生态（高质量路线）

| 指标 | 数值 |
|------|------|
| 显存 | 12GB（GGUF Q4）~ 24GB（FP16） |
| 速度 | RTX 4090 上 ~12-28s/张 |
| 质量 | 最佳提示遵循、文字渲染 |
| 动漫生态 | 较少（~500 LoRA），但 PuLID/InstantCharacter 支持 |
| 授权 | Dev 版非商用，Schnell 版 Apache 2.0 |

### 3.3 Neta Lumina（捏Ta）— 国产二次元

> Hugging Face: neta-art/Neta-Lumina  
> 基于 Lumina-Image-2.0（上海 AI 实验室）

| 指标 | 数值 |
|------|------|
| 显存 | **8GB** ✅ |
| 风格 | 二次元插画、海报、分镜 |
| 语言 | 原生中文/英文/日文 |
| 训练数据 | 1300 万张二次元图像 |
| 输出 | 1024×1024 + 各种比例 |
| 授权 | 未明确 |

**特点**：国内团队，中文 prompt 支持好，显存友好。

### 3.4 模型选择建议

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| **本地 3060 12GB 起步** | **SDXL + PuLID v1.1 + 动漫微调** | 12GB 可用，零样本身份保持，动漫生态丰富 |
| **4090 主力推理** | FLUX + PuLID-FLUX | 质量更高，提示遵循更好 |
| **A100 80GB** | FLUX 全精度 + InstantCharacter | 最强配置，可同时加载多个身份方案 |
| 纯文生图备用 | Neta Lumina / Anima / RouWei-0.6 | 中文友好，二次元特化，即装即用 |

## 四、角色一致性方案选型

> ⚠️ **前提：我们不训练模型，只使用社区现成的预训练权重。**

所有方案必须在**零样本（zero-shot）**前提下工作，即给一张参考图就能用，不需要微调/LoRA 训练。

### 4.1 方案对比

| 方案 | 是否需要训练 | 3060 12GB | 效果 | 说明 |
|------|------------|-----------|------|------|
| **PuLID v1.1（SDXL）** | 否（零样本） | ✅ 12GB | ⭐⭐⭐⭐ | **首推**。给参考脸→保持身份生成新图 |
| PuLID-FLUX | 否（零样本） | ❌ 需16GB | ⭐⭐⭐⭐⭐ | 质量更高，需 4090 |
| InstantCharacter | 否（零样本） | ❌ 需22GB | ⭐⭐⭐⭐ | FLUX 版，4090 可跑 |
| InstantID | 否（零样本） | ❌ 需16GB | ⭐⭐⭐⭐ | SDXL 版，生态成熟 |
| FLUX.2 klein 多参考 | 否（原生支持） | ⚠️ 量化13GB | ⭐⭐⭐⭐⭐ | 原生多参考，无需额外模块 |
| IP-Adapter-FaceID | 否（零样本） | ✅ 10GB | ⭐⭐⭐ | 轻量参考控制 |
| 纯文本 prompt | 否 | ✅ | ⭐⭐ | 默认回退方案 |

### 4.2 推荐流程

```
用户提供角色参考图？
  ├─ 是 → PuLID v1.1（SDXL 版，3060 可跑）
  │        如果 3060 不够 → 用 4090 跑 PuLID-FLUX 或 FLUX.2 klein
  │
  └─ 否 → 纯文本 prompt 生成（角色卡描述 + 场景情感标签 + 风格指导）

质量不够满意？
  └─ 换社区现成的高质量动漫模型（Illustrious / RouWei / Anima）
      而不是自己训练
```

> **注意**：我们不做 LoRA 训练，不动训练代码。所有"更好的质量"都通过换基座模型或升级身份保持方案来实现。

## 五、按硬件部署方案

### 5.1 本地 RTX 3060 12GB

```
基座模型: SDXL + Illustrious / RouWei-0.6（动漫微调）
身份保持: PuLID v1.1（SDXL 版，12GB 可跑）
回退方案: 纯文本 prompt + 角色卡描述
量化: 不需要，SDXL 原生 8GB
```

### 5.2 Linux 服务器 1 — 2× RTX 4090 24GB

```
基座模型: FLUX.1-dev / Schnell（FP8 或 GGUF）
身份保持: PuLID-FLUX 或 InstantCharacter 或 FLUX.2 klein（原生多参考）
批量生成: 并行 2 卡，每卡独立推理
```

### 5.3 Linux 服务器 2 — A100 80GB

```
基座模型: FLUX.1-dev（FP16 全精度）
身份保持: PuLID-FLUX + InstantCharacter 双方案同时加载
高分辨率: 2048×2048+ 输出
批量: 大批量生成，多个身份保持方案轮换
```

## 六、整体架构

```
[输入]
场景分割数据 (bgm_segments.json)
  ├─ 场景文本摘要
  ├─ 情感标签（日常/悬疑/战斗...）
  └─ 时间轴位置

角色卡 (docs/角色卡.md)
  ├─ 角色外貌描述
  └─ 角色参考图（可选，用户提供）

[Prompt 组装]
  场景文本 + 角色描述 + 情感氛围 + 风格指令
  → 结构化 prompt

[生成]
  用户提供参考图 ──→ PuLID / IP-Adapter → 保持身份
  无参考图 ──→ 纯文本 prompt → SDXL / FLUX

[输出]
  output/illustrations/
  ├── chapter_001/
  │   ├── 000_daily.jpg
  │   ├── meta.json
  └── illustration_index.json
```

## 七、推荐路线

### 第一阶段：SDXL + PuLID v1.1（本地 3060 12GB ✅）

```bash
# 零样本，即装即用，不需要训练
pip install diffusers transformers accelerate insightface
# 下载 PuLID v1.1 权重 + SDXL 基座 + 动漫微调模型
# 启动推理
```

**这个阶段就能跑通完整流程**：用户提供参考图 → PuLID 保持身份 → 生成插图。

### 第二阶段：升级到 FLUX（4090 24GB）

当本地 3060 不够用时（比如需要更高质量），把推理切换到 4090 服务器上：
- FLUX.1-dev/schnell + PuLID-FLUX
- 或 FLUX.2 klein（原生多参考）

### 第三阶段：A100 高分辨率 + 多方案并行

A100 80GB 可以同时加载多个模型，批量生成高分辨率插图。

> 所有阶段都使用社区预训练权重，**零训练成本**。

## 八、关注但不作为首选

| 项目 | 原因 |
|------|------|
| **SD3.5 Large** | 18GB 显存 > 12GB，LoRA 生态小（仅 50），不如 SDXL 实用 |
| **ComfyUI 工作流** | 适合手动操作，自动化集成需要额外封装 |
| **Qwen Image** | 质量好但非动漫特化，作为备选 |
| **Z-Image** | 质量好但非动漫特化 |

---

## 九、结论

**最推荐路线**：

1. **起步（本地 3060 12GB）**：SDXL + PuLID v1.1 + 动漫微调模型（Illustrious / RouWei-0.6）
2. **主力（4090 24GB）**：FLUX + PuLID-FLUX 或 FLUX.2 klein（原生多参考）
3. **进阶（A100 80GB）**：FLUX 全精度 + 多个身份保持方案并行

**全程零训练**，全部使用社区现成权重。
