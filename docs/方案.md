# Novel Voice Cast — 开发方案

## 背景

我喜欢看轻小说，但轻小说的对话通常不标注说话人，只用「」包裹。市面上的 TTS 工具要么只有单一朗读者，要么配置复杂、需要自己折腾音色克隆。

这个项目的目标很简单：**给定一本已标注好说话人的小说 + config 配置 → 一键合成带角色演绎的音频文件**。

## config.yaml 示例

```yaml
# 小说文件
novel:
  text_path: "novels/novel.txt"        # 小说文本
  labels_path: "novels/labels.txt"     # 角色标注

# Ollama 配置（用于性别识别、情感标注）
ollama:
  base_url: "http://172.31.102.237:11434"
  model: "qwen3:4b"

# 音色克隆引擎选择：voxcpm 或 indextts2
clone_engine: "voxcpm"  # 默认使用 VoxCPM

# 角色音频配置
characters:
  - name: "罗伦斯"
    reference_audio: "voices/ronald.wav"
  - name: "赫萝"
    reference_audio: "voices/holo.wav"
  
  # 其他角色自动用预设（根据性别）

# 功能开关
features:
  gender_identify: true        # 自动识别性别
  emotion_label: true          # 情感标注
  denoise: true                # 音频去噪

# 输出配置
output:
  dir: "output"                    # 输出目录
  filename: "full_volume"          # 输出文件名（不含扩展名）
  format: "mp3"                    # 输出格式：wav 或 mp3
  bitrate: "64k"                   # MP3 码率：64k, 128k, 192k, 320k（仅 mp3 有效）

# TTS 配置
tts:
  male_voice: "zh-CN-YunxiNeural"     # edge-tts 男声
  female_voice: "zh-CN-XiaoxiaoNeural" # edge-tts 女声

# VoxCPM 配置（clone_engine: voxcpm 时使用）
# 模型下载：https://github.com/Rikorose/DeepFilterNet 或联系项目作者
# 模型结构：
#   VoxCPM2/
#   ├── audiovae.pth          (376 MB)
#   ├── config.json           (4 KB)
#   ├── model.safetensors     (4.5 GB)
#   ├── tokenizer.json        (3.6 MB)
#   └── tokenizer_config.json (5 KB)
voxcpm:
  model_path: "backend/models/VoxCPM2"

# IndexTTS2 配置（clone_engine: indextts2 时使用）
# 模型下载：https://github.com/Rikorose/DeepFilterNet 或联系项目作者
# 模型结构：
#   checkpoints/IndexTTS-2/
#   ├── bpe.model             (476 KB)
#   ├── config.yaml           (2.8 KB)
#   ├── feat1.pt              (57 KB)
#   ├── feat2.pt              (375 KB)
#   ├── gpt.pth               (3.4 GB)
#   ├── s2mel.pth             (1.2 GB)
#   └── wav2vec2bert_stats.pt (9 KB)
indextts2:
  model_path: "backend/models/checkpoints/IndexTTS-2"
  device: "cuda"  # cuda 或 cpu
```

## 流程说明

```
┌─────────────────────────────────────────────────────────┐
│  run.py                                                 │
│  ├── 1. 解析小说 (parser.py)                             │

│  │                                                       │
│  ├── 2. 识别性别 (gender_identifier.py) [可选]           │
│  │      Ollama 分析 → 保存到 gender_results.json         │
│  │                                                       │
│  ├── 3. 情感标注 (emotion_labeler.py) [可选]             │

│  │                                                       │
│  ├── 4. TTS 合成 (voice_clone.py / preset.py)           │
│  │      VoxCPM: 罗伦斯、赫萝 (约30s/条)                  │
│  │      edge-tts: 其他角色 (约0.5s/条)                   │
│  │      → 1287个音频片段                                 │
│  │                                                       │
│  ├── 5. 音频拼接 (splicer.py)                            │
│  │      按顺序拼接 + 间隔 + 淡入淡出                      │
│  │      → full_volume.wav                                │
│  │                                                       │
│  └── 6. 去噪 (denoise.py) [可选]                         │
│         DeepFilterNet3                                   │
│         → full_volume_denoised.wav                       │
└─────────────────────────────────────────────────────────┘
```

## 技术选型

| 模块 | 选型 | 理由 |
|------|------|------|
| 配置 | **YAML** | 人类可读，支持注释 |
| 音频处理 | **pydub** + **soundfile** | 格式转换、拼接 |
| 音色克隆 | **VoxCPM** / **IndexTTS2** | 中文效果好 |
| 预设 TTS | **edge-tts** / **pyttsx3** | 在线/离线可选 |
| 性别/情感 | **Ollama** (qwen3:4b) | 本地运行 |
| 去噪 | **DeepFilterNet3** | 效果好，轻量 |

## 阶段 7：BGM 配乐（待实现）

### 需求描述

为整卷小说自动配置背景音乐（BGM），增强听书体验。

### 流程设计

```
整卷小说 → 大模型分析分段 → 标记 BGM 类型 → AI 生成 BGM → 混音输出
```

### 详细步骤

1. **小说分段**
   - 大模型阅读整卷小说
   - 按事件/场景划分多个部分
   - 例如：日常对话 → 紧张悬疑 → 战斗热血 → 温馨结尾

2. **BGM 类型标记**
   - 大模型为每个部分标记适合的 BGM 类型
   - 类型示例：
     - `日常`：轻松、温馨、日常聊天
     - `悬疑`：紧张、神秘、诡异
     - `战斗`：热血、激昂、紧张
     - `悲伤`：忧伤、沉重、感人
     - `浪漫`：温柔、甜蜜、抒情
     - `史诗`：宏大、壮丽、震撼

3. **BGM 生成**
   - 集成开源 AI BGM 生成项目
   - 候选项目：
     - [MusicGen](https://github.com/facebookresearch/audiocraft) - Meta 的音乐生成模型
     - [Riffusion](https://github.com/riffusion/riffusion) - 基于频谱图的音乐生成
     - [AudioLDM](https://github.com/haoheliu/audioldm) - 音频扩散模型
   - 根据 BGM 类型生成对应的背景音乐

4. **混音输出**
   - 将 BGM 与语音合成结果混合
   - BGM 音量低于语音（约 20-30%）
   - 场景切换时 BGM 平滑过渡

### 配置示例

```yaml
# config.yaml
bgm:
  enabled: true
  volume: 0.25  # BGM 音量（0-1）
  fade_duration: 2000  # 场景切换淡入淡出时间（ms）
  types:
    daily: "轻松温馨的日常背景音乐"
    suspense: "紧张悬疑的背景音乐"
    battle: "热血激昂的战斗背景音乐"
    sad: "悲伤感人的背景音乐"
    romantic: "温柔浪漫的背景音乐"
    epic: "宏大壮丽的史诗背景音乐"
```

### 技术挑战

- BGM 生成质量
- 场景切换的平滑过渡
- BGM 与语音的音量平衡
- 长时间音频的生成效率

## 阶段 8：人声提取（Vocal Separation）— 已实现 ✅

> 参考文档：[`stemdeck-介绍与使用指南.md`](./stemdeck-介绍与使用指南.md) | 代码：[`backend/app/core/vocal_separator.py`](../backend/app/core/vocal_separator.py) | CLI: [`scripts/vocal_separate.py`](../scripts/vocal_separate.py)

### 需求描述

用户可能有动漫/影视片段，其中包含想克隆的目标角色的人声，但片段中混有 BGM、环境音、音效等。直接拿这种片段做音色克隆效果很差。需要一个前置步骤将人声从混合音频中分离出来。

### 方案

使用 Meta Demucs `htdemucs_6s` 模型进行音频分轨（通过 `demucs` PyPI 包，无需启动 StemDeck Web 服务）：

```
用户提供的音频片段 (MP3/WAV/FLAC)
        ↓
  ffmpeg 转码 → 16bit 44.1kHz WAV
        ↓
  Demucs (htdemucs_6s) 分离
        ↓
  ┌─────────┬──────────┬──────┐
  │ Vocals  │  Drums   │ Bass │  ← 6 个独立音轨
  │ (人声)   │  Guitar  │ Piano│
  │         │  Other   │      │
  └────┬────┴──────────┴──────┘
       ↓
  Vocals → DeepFilterNet 二次去噪（可选）
       ↓
  干净的参考音频 → VoxCPM 音色克隆
```

### 使用方法

```bash
# 提取人声（默认只保留 vocals.wav）
python scripts/vocal_separate.py my_audio.mp3

# 指定输出目录和设备
python scripts/vocal_separate.py my_audio.mp3 --output output/vocals --device cuda

# 保留所有 6 个音轨
python scripts/vocal_separate.py my_audio.mp3 --keep-all

# 使用 CPU（没有 NVIDIA 显卡时自动降级）
python scripts/vocal_separate.py my_audio.mp3 --device cpu
```

### 在代码中使用

```python
from app.core.vocal_separator import separate

# 提取人声，仅返回 vocals
result = separate("my_clip.mp3", device="cuda")
vocals_path = result["vocals"]
# → output/vocal_separation/<filename>/stems/vocals.wav

# 保留全部 6 个音轨
result = separate("my_clip.mp3", keep_all_stems=True)
for name, path in result.items():
    print(name, path)
```

### 输出目录结构

```
output/vocal_separation/<input_filename>/
└── stems/
    ├── vocals.wav    # 人声（默认保留）
    ├── drums.wav     # 鼓（--keep-all 时保留）
    ├── bass.wav      # 贝斯
    ├── guitar.wav    # 吉他
    ├── piano.wav     # 钢琴
    └── other.wav     # 其他乐器
```

### 技术选型

| 组件 | 说明 |
|------|------|
| **Demucs** (htdemucs_6s) | Meta AI 开源音频分轨模型，6 音轨 |
| **soundfile** | WAV 写入后端（兼容 torchaudio 2.7+） |
| **ffmpeg** | 音频转码（输入格式兼容） |
| **DeepFilterNet** | 已集成，可选二次去噪 |

### 性能

| 硬件 | 30 秒片段 | 5 分钟片段 |
|------|-----------|-----------|
| NVIDIA GPU (CUDA) | ~5 秒 | ~1 分钟 |
| CPU only | ~30 秒 | ~5-10 分钟 |

首次运行会自动下载模型权重（~170 MB），之后缓存使用。

### 注意事项

1. Demucs 主要针对歌曲（唱歌+伴奏）训练，动漫台词分离效果需要实测验证
2. GPU 竞争：Demucs (~3-5GB)、VoxCPM (4-8GB)、ACE-Step (~4GB) 需串行，不能同时跑
3. 无需启动 StemDeck Web 服务，直接通过 `demucs` PyPI 包调用
4. 分离后可用 DeepFilterNet 做二次去噪，进一步提升人声纯净度
